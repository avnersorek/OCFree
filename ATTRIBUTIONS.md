# Attributions

This implementation is original work by Avner Sorek. It was informed by the
following projects and public benchmarks, which are listed as design references
only.

## Design references

- **@openclaw/opencode-provider (OpenClaw)** — OpenClaw project. Reference for
  integrating OpenCode with OpenClaw plugin conventions.
  <https://github.com/openclaw/openclaw>
- **nashingofteeth/opencode-free-models-benchmark** — no license; ideas only.
  Reference for benchmarking free OpenCode models.
  <https://github.com/nashingofteeth/opencode-free-models-benchmark>
- **grigio/opencode-benchmark-dashboard** — no license; ideas only. Reference
  for presenting benchmark results.
  <https://github.com/grigio/opencode-benchmark-dashboard>
- **@luoyingwen/opencode-chat-bot** — MIT; ideas only. Reference for chat-driven
  OpenCode workflows.
  <https://github.com/luoyingwen/opencode-chat-bot>
- **arthursoares/openclaw-llm-bench** — MIT; ideas only. Reference for
  OpenClaw-oriented model benchmarking.
  <https://github.com/arthursoares/openclaw-llm-bench>
- **BenchLM coding leaderboard** — public coding model leaderboard used as an
  online quality rating source.
  <https://benchlm.ai/coding>
- **SWE Atlas Codebase QnA** — public benchmark used for the Big Pickle seed
  score. This score uses a different benchmark scale from BenchLM coding scores.
  <https://github.com/PhillipChaffee/big-pickle-swe-atlas>

No code was copied from the unlicensed projects
(`nashingofteeth/opencode-free-models-benchmark` and
`grigio/opencode-benchmark-dashboard`); this repository only draws on their
general ideas.
